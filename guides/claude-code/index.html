Point Claude Code at OrcaRouter

Claude Code has no endpoint setting in its interface. The endpoint comes from environment variables, which is why you cannot find it. Set five variables and every session runs through OrcaRouter instead of Anthropic directly.

Why there is no option to find

Read this first so you stop looking for a menu item that does not exist.

Claude Code is a client. It runs on your machine and calls a model at an address you supply. The default address is Anthropic's. There is no provider dropdown, nothing under a settings menu, and nothing in /config that changes the endpoint.

The address comes from ANTHROPIC_BASE_URL and the credential comes from ANTHROPIC_AUTH_TOKEN. Set both and Claude Code talks to OrcaRouter. Anthropic documents this pattern as an LLM gateway deployment, so it is a supported topology rather than a workaround.

One rule before anything else

If you already have a Claude subscription login saved, setting the base URL alone does not replace it. Per Anthropic's documentation, requests still route through the gateway, but the saved login stays the active credential. Set the auth token and blank the API key variable as shown below, or your requests will authenticate against Anthropic instead of OrcaRouter.

Install

Two paths. The installer does everything on this page in one command, including a smoke test. The manual path is below if you prefer to see every step.

Fastest: the installer

This installs Claude Code if it is missing, writes the configuration, and smoke-tests the connection. It prompts for your key, or reads ORCA_KEY from the environment to run unattended. Prefer the environment variable over a key flag, because a flag lands in your shell history.

curl -fsSL https://api.orcarouter.ai/install.sh | sh -s -- --tool claude-code

Windows PowerShell:

& ([scriptblock]::Create((irm https://api.orcarouter.ai/install.ps1))) -Tool claude-code

Manual: install Claude Code

npm install -g @anthropic-ai/claude-code

On Windows, Claude Code needs Git Bash. Install Git for Windows, then set CLAUDE_CODE_GIT_BASH_PATH to your bash executable, for example C:\Program Files\Git\bin\bash.exe.

Configure

Your key comes from the dashboard at orcarouter.ai/console and always starts with sk-orca-. Add these lines to your shell profile, then reload it.

export ANTHROPIC_BASE_URL="https://api.orcarouter.ai"
export ANTHROPIC_AUTH_TOKEN="PASTE_YOUR_ORCAROUTER_KEY"
export ANTHROPIC_API_KEY=""   # leave this one empty on purpose
export ANTHROPIC_MODEL="orcarouter/auto"
export ANTHROPIC_SMALL_FAST_MODEL="anthropic/claude-haiku-4.5"

Reload the shell, or the old environment stays in memory and you will test the wrong thing:

source ~/.bashrc    # or ~/.zshrc, or open a new terminal
1

Base URL excludes /v1

Claude Code appends /v1/messages itself. Adding /v1 produces /v1/v1/messages and a 404. This is the opposite of what the OpenAI and Anthropic SDKs need, where the base URL does include /v1.

2

Use the auth token, not the API key

ANTHROPIC_AUTH_TOKEN is sent as Authorization: Bearer, which is what a gateway expects. ANTHROPIC_API_KEY is sent as x-api-key and is treated as a direct-Anthropic credential.

3

Blank the API key variable on purpose

Set ANTHROPIC_API_KEY="" even though it looks redundant. If it holds a value, Claude Code treats it as an Anthropic credential, can prompt you once to approve it over a saved login, and can fall back to Anthropic. An empty string prevents that fallback.

4

Keep the ordering right

Assignments expand when the profile loads. If you write ANTHROPIC_AUTH_TOKEN="$ORCAROUTER_KEY" and the key is defined lower in the file, or injected by a secrets manager afterwards, the token expands to empty and every request fails with an auth error. Define the key before the token, or read it from a file that loads first.

Verify

One command tells you whether it worked. Do not skip it and start a long session first.

claude -p "Reply with exactly: OK"

You should see OK. If you do not, the troubleshooting table below covers the causes in the order they usually appear.

Then start an interactive session with claude. Use /status to confirm which endpoint and credential are live, and /model to switch models. The model list comes from the same catalog our API serves.

Gotchas worth reading twice

Each of these produces a confusing failure that looks like a broken gateway.

Blank ANTHROPIC_API_KEY

The single most common cause of "it is still using my Anthropic account." An empty string is not the same as an unset variable here, because unset lets Claude Code fall back to a saved login. Set it to empty explicitly.

Restart the shell, not just the editor

Environment variables are read when the process starts. An editor that was already open keeps the old environment, including its Claude Code extension, which is why a working terminal can sit next to a broken editor tab.

Keys are plaintext in your profile

A shell profile is easy to commit to a dotfiles repo or paste into a gist. Give the key a spend cap and an expiry when you create it in the dashboard. If it leaks, delete it there and issue a new one. Creating keys with a name, a credit limit and an expiration takes ten seconds and saves an incident.

The VS Code extension has no separate setting

Anthropic's official extension runs the same CLI inside the editor and reads the same configuration. Set the environment variables or the settings file, and the extension follows. There is no in-editor endpoint field.

Choosing models

Model names use the vendor/model format. Pick either a specific model or a router that decides per request.

SettingWhat it does
orcarouter/autoA named router that exists on every account. It sizes the model to each request, so routine turns go to a cheaper model and harder turns go stronger. This is the simplest default.
orcarouter/fusionRuns a panel of frontier models and returns the strongest answer through one slug. Use it when a session matters more than it costs.
anthropic/claude-opus-4.8Pin a specific frontier model when output determinism matters.
anthropic/claude-sonnet-5A mid-tier pin for long coding sessions where cost per turn matters.
anthropic/claude-haiku-4.5A good value for ANTHROPIC_SMALL_FAST_MODEL, which Claude Code uses for background work like titles and summaries.

Read the live list any time with:

curl -s https://api.orcarouter.ai/v1/models    # public, no key needed

What you get by routing instead of calling Anthropic directly:

CostProvider list price with nothing added on top, and cached reads billed at the provider's cache rate.
FailoverA chain of models, so an upstream error or a throttle is absorbed before the first byte reaches you.
Session affinitySend one session header and a conversation stays on the same model with a warm prompt cache, which is where long agent sessions save money.
ReceiptsCost and routing decisions per request, readable inline or looked up afterwards by request id.
ControlsKeys with spend caps and expiries, workspace budgets, and zero data retention by default.

Troubleshooting

Find your symptom, check the cause, apply the fix.

SymptomLikely causeFix
Auth error or 401 on every requestThe token expanded to empty, or the key is wrong, or it expiredPrint the length of the token variable, not its value. If it is 0, you have an ordering problem. Otherwise issue a fresh key in the dashboard.
404 on a path containing v1/v1/v1 is in the base URLSet the base URL to https://api.orcarouter.ai with no path suffix.

Honest limits

This guide covers the variables we have tested: the base URL, the auth token, the empty API key, the model names and the smoke command. Claude Code ships updates often, so if a future build changes how it reads credentials, the smoke command is what tells you. We have not verified every optional Claude Code flag against our gateway, so when a setting is not documented here, test it and tell us rather than assuming it works.
